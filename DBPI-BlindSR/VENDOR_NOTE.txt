The upstream repository does not contain a LICENSE file. Do not treat
this snapshot as carrying a license the authors did not grant.

The upstream README states that the code is based on KernelGAN
(https://github.com/sefibk/KernelGAN). imresize.py in this tree is
byte-identical to KernelGAN imresize.py. The other Python modules are
adapted from that repository (same filenames; the networks and the
training loop are the DBPI changes). KernelGAN is distributed under the
Weizmann Institute / Yeda academic non-commercial license, copied here
as KERNELGAN_LICENSE.txt. That file is the KernelGAN license, not a
LICENSE added by the DBPI authors.

This VENDOR_NOTE.txt was added in wettability-DWJ. It is not part of
the upstream commit. No pretrained weights are included; DBPI trains
from the input image.
